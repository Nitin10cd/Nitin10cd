### Compliance Copilot — AI That Answers Security & Policy Questions From Your Own Documents

A RAG-based compliance assistant for the questionnaires, RFPs and vendor reviews that organizations go through before finalizing a deal, while employees keep asking HR and IT the same policy questions. It generates answers **only from the documents a company already has**: heading-aware chunks, Gemini embeddings, Qdrant with company/category filters, FlashRank re-ranking, then a grounded answer with a groundedness check that labels every response **HIGH / REVIEW / UNKNOWN**. Anything uncertain is flagged for a human, and no retrieved context means "I don't have that". The flow runs as a **LangGraph** Planner → Retriever → Responder graph, with **Portkey** for LLM routing with fallback and **Logfire** tracing. **NeMo Guardrails** block jailbreaks and off-topic prompts before they reach the answer LLM, and vendor answers, contracts and public questions are wrapped as untrusted data. Ships with 8 modules: Policy Chat, Questionnaire & RFP Drafter, Trust Center, Slack Helpdesk, Vendor Risk Review, Contract/DPA Checker, Audit Readiness (SOC 2, ISO 27001, GDPR) and Policy Change Impact.

### NeoDB — A Database Engine Built From Scratch

A complete database ecosystem across four independent components: a **C++17 SQL engine** with disk persistence, a **Node.js BaaS server**, a **TypeScript ORM**, and a **React Studio UI** — no SQLite, no PostgreSQL underneath (**41 tests**). Includes a hand-written lexer and recursive-descent SQL parser, 4KB slotted-page binary storage (the same format PostgreSQL uses internally), an LRU buffer pool manager, a B+ Tree index built from scratch, and a Write-Ahead Log for full ACID crash recovery. The C++ engine and Node.js layer communicate over a Unix socket, mirroring PostgreSQL's own architecture.

### StartCo — Multi-Agent AI Workforce Platform

A multi-tenant SaaS platform giving solo founders an on-demand AI workforce across **Sales, Marketing, HR, Finance, Document Verification and Market Research**. Built across three cooperating services — a Next.js frontend, a Node.js/Express orchestration backend, and a Django agent-execution engine — every business function runs as an independent agent under a shared **Planner → Worker → Tool Registry** contract. The Market Research agent runs as an explicit **LangGraph state machine** (planning → competitor analysis → trends → persona → SWOT → report). Also ships a **RAG interview engine** and an **AES-encrypted API key vault** — every company's LLM provider key is resolved through an internal gateway, so the Django agent layer never talks to an LLM provider directly. Document verification and finance calculations are deliberately LLM-free (checksum algorithms and pure arithmetic) where precision matters.

### Neo Net — Social Media Backend with Encrypted Chat

A production-style social backend built around three hard problems: **fan-out at scale, async pipelines, and encryption at rest**. Notifications are decoupled via Django Signals, Celery and Redis Pub/Sub, so a spike from one notification type never degrades another. Chat runs over Django Channels with **AES-256-GCM** — each conversation gets its own key, scoping any compromise to a single conversation. A separate AI content pipeline uses LangChain + Groq to generate a script, source stock footage from Pexels, render video with MoviePy, and auto-post to the feed — all inside a Celery queue. Ships with a GitHub Actions CI/CD pipeline building a fresh Docker image on every push.

### HireReady — AI Interview Preparation Platform

AI-powered, resume-based mock interviews combined with a live expert-consulting marketplace and real-time coding practice. Resumes are parsed into a **vector database** so questions come from a candidate's actual experience, not generic prompts. Each session produces a detailed **PDF report** with per-question scoring. The expert side runs on **WebRTC** for 1:1 video, with a credit system and a shared TL Draw canvas for system-design rounds. Long-running jobs — PDF generation, email, AI processing — are offloaded to **BullMQ** queues in Docker.
