## Featured Builds

### NeoDB — A Database Engine Built From Scratch

A complete database ecosystem across four independent components: a C++17 SQL engine with disk persistence, a Node.js BaaS server, a TypeScript ORM, and a React Studio UI — no SQLite, no PostgreSQL underneath. Includes a hand-written lexer and recursive-descent SQL parser, 4KB slotted-page binary storage (the same format PostgreSQL uses internally), an LRU buffer pool manager, a B+ Tree index built from scratch, and a Write-Ahead Log for full ACID crash recovery. The C++ engine and Node.js layer communicate over a Unix socket, mirroring the architecture PostgreSQL itself uses.

`C++17` `CMake` `Node.js` `TypeScript` `React` `Socket.IO`

**Repo:** https://github.com/Nitin10cd/NeoDB_Custom_Database_Complete_Doc

### StartCo — Multi-Agent AI Workforce Platform

A multi-tenant SaaS platform giving solo founders an on-demand AI workforce across Sales, Marketing, HR, Finance, Document Verification, and Market Research. Built across three cooperating services — a Next.js frontend, a Node.js/Express orchestration backend, and a Django agent-execution engine — every business function runs as an independent agent under a shared Planner → Worker → Tool Registry contract. The Market Research agent runs as an explicit LangGraph state machine (planning → competitor analysis → trends → persona → SWOT → report). Document verification and finance calculations are deliberately kept LLM-free, using checksum algorithms and pure arithmetic where precision matters. Every company's LLM provider key is AES-encrypted and resolved through an internal gateway — the Django agent layer never talks to an LLM provider directly.

`Next.js` `TypeScript` `Express.js` `Django` `LangGraph` `MongoDB` `Redis` `BullMQ` `Socket.IO`

**Repo:** https://github.com/Nitin10cd/Company_os

### NeuroLearn — Multi-Tenant College Management CRM

A full-stack college CRM covering the complete academic lifecycle — institute onboarding, curriculum management, attendance, MCQ auto-grading, a three-stage result-publishing workflow, a transaction-safe library system, and a placement cell. Four isolated authentication flows (Institute, Admin, Faculty, Student) enforce tenant isolation at the query level rather than the UI. Analytics run as 14 concurrent MongoDB aggregations via `Promise.all`, cutting response time from over 2 seconds to under 500ms. Library book issuance uses MongoDB session transactions to prevent over-issuance under concurrent approvals. Includes a real-time collaborative whiteboard built on WebRTC and Socket.io.

`Node.js` `Express.js` `MongoDB` `React.js` `Socket.io` `WebRTC`

### Neo Net — Social Media Backend with Encrypted Chat

A production-style social media backend built around three hard backend problems: fan-out at scale, async pipelines, and encryption at rest. Notifications are decoupled via Django Signals, Celery, and Redis Pub/Sub, so a spike from one notification type never degrades another. Chat runs over Django Channels with AES-256-GCM encryption — each conversation gets its own key, scoping any potential key compromise to a single conversation. A separate AI content pipeline uses LangChain and Groq to generate a script, source stock footage from Pexels, render video with MoviePy, and auto-post to the feed, all running inside a Celery queue. Ships with a GitHub Actions CI/CD pipeline building a fresh Docker image on every push.

`Python` `Django` `PostgreSQL` `Redis` `Celery` `LangChain` `Docker`

### HireReady — AI Interview Preparation Platform

Combines AI-powered resume-based mock interviews with a live expert-consulting marketplace and real-time coding practice. Resumes are parsed into a vector database so interview questions are generated from a candidate's actual experience rather than generic prompts. Each session produces a detailed PDF report with per-question scoring. The expert-consulting side runs on WebRTC for 1:1 video sessions, with a credit system for engagement and a shared canvas (TL Draw) for system-design rounds. Long-running jobs — PDF generation, email delivery, AI processing — are offloaded to BullMQ queues running in Docker.

`Next.js` `MongoDB` `LangChain.js` `WebRTC` `Socket.IO` `Docker` `BullMQ`

---

### Stack Network — AI-Powered Job Matching Platform

A professional networking and job-matching platform where every profile is rated by an AI model that recalculates the score on every edit, and job listings are filtered by that rating. Includes a verified-company system with admin controls and a public complaint mechanism that has resulted in 30+ fraudulent company listings being banned. Articles go through AI-based originality and quality monitoring before publishing. The stack is type-safe end to end — Zod validation on every API boundary, Prisma for fully typed database access.

`Next.js` `Prisma` `Supabase` `PostgreSQL` `TypeScript` `Socket.io`
